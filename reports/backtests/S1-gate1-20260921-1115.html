✓ PASSES Gate 1: eligible for paper trading

Long when price is above the slow moving average and the fast average is above the slow one. Exit when that trend ends or the trailing stop (highest close since entry - k x ATR) is hit. Position size comes from the stop distance, so volatile assets get smaller positions.

Settings chosen on 1995-10-18 – 2017-06-12 only (fast=20, slow=200, atr_mult=2.5), then tested on 2017-06-12 – 2026-09-21, which they never saw.

Read this before trusting the numbers

  • 18 parameter combinations were tried in this run (18 for S1 in total). The more variants are tried, the more likely a good result is luck.
  • Symbols were picked today, knowing which assets did well (e.g. Bitcoin, the Nasdaq). That hindsight flatters results, especially before each asset became popular.
  • Prices are daily bars from Yahoo Finance, dividend-adjusted. Live fills use Alpaca's prices.
  • A backtest is not a forecast. Gate 2 (90+ days of paper trading) decides what survives.
